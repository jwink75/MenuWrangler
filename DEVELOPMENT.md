# MenuWrangler Development & Build Guide

## Overview
MenuWrangler is a modern menu bar organizer for macOS, derived from Jordan Baird's open-source *Ice* project with updated macOS 14/15/26 compatibility, decoupled dependencies, and custom menu bar folder features.

---

## 1. Building & Deploying

To compile, deep-sign, and install MenuWrangler without triggering Gatekeeper false positives or sync collision issues, use the automated build script:

```bash
./scripts/build.sh
```

### What `./scripts/build.sh` Handles:
1. **Sync Conflict Cleaning**: Removes any `(conflicted copy)` files generated by cloud storage sync engines (e.g. Dropbox).
2. **Out-of-Tree DerivedData**: Builds using standard Xcode DerivedData (`~/Library/Developer/Xcode/DerivedData`) rather than inside the sync folder.
3. **Deep Recursive Code Signing**: Signs the entire `.app` bundle using your local Apple Development certificate or ad-hoc identity (`codesign --force --deep --sign ...`).
4. **Gatekeeper Quarantine Removal**: Clears quarantine extended attributes (`xattr -cr /Applications/MenuWrangler.app`) so macOS does not display "damaged app" warnings.
5. **Deployment & Launch**: Deploys cleanly to `/Applications/MenuWrangler.app` and launches the application.

---

## 2. Gatekeeper & Code Signing Considerations (Fix 7)

### Why "Damaged App" Alerts Occur
macOS Gatekeeper displays *“App is damaged and can't be opened”* whenever:
- **Inner Binary Mismatch**: Pre-compiled frameworks (like Sparkle in upstream Ice) have different cryptographic signatures than the host app. Sparkle has been completely removed in MenuWrangler to resolve this.
- **Sync Duplicates**: Cloud sync engines writing duplicate files into an `.app` bundle breaks the code signature seal.
- **Quarantine Flags**: When downloaded or copied between systems, macOS applies `com.apple.quarantine`.

### Manual Signing Commands
- **Sign with Apple Development Certificate**:
  ```bash
  codesign --force --deep --sign "Apple Development: jacob.winkler@mac.com (34WGK88W63)" /Applications/MenuWrangler.app
  ```
- **Ad-Hoc Signing (Local Mac without certificate)**:
  ```bash
  codesign --force --deep --sign - /Applications/MenuWrangler.app
  ```
- **Clear Quarantine**:
  ```bash
  xattr -cr /Applications/MenuWrangler.app
  ```

## 3. Window Discovery Pipeline & Modern macOS Fallbacks (Fix 6)

On modern macOS versions (macOS 14/15+), WindowServer enforces strict window isolation and anonymization:
1. **Primary Discovery**: Queries `CGSGetProcessMenuBarWindowList` to retrieve active menu bar status item window IDs.
2. **Fallback Discovery**: If the private CGS API returns empty or is restricted by runtime shims, [`Bridging.swift`](Ice/Bridging/Bridging.swift) automatically falls back to querying `CGWindowListCopyWindowInfo([.optionAll], kCGNullWindowID)` for status bar windows at layer 25.
3. **Visual Fallbacks**: If screen captures return blank/transparent buffers, [`LayoutBarItemView.swift`](Ice/UI/LayoutBar/LayoutBarItemView.swift) dynamically displays application icons (`NSRunningApplication.icon`) and system SF Symbols.
